### TF-2: Cold-network font-swap CLS (Completed)

1. Attributed the `--font-delay-ms=1500` shifts (`0.047–0.334`) to two root causes: (a) `M PLUS 1 Code` (`0.50em` advance width) falling back to `ui-monospace` (`~0.60em` advance width), causing eyebrows, breadcrumbs, and compact table headers to unwrap when `.woff2` arrived; and (b) `ch`-based width caps (`68ch` / `66ch`) on `.f12-body-copy` and `.f12-muted-copy` shrinking by ~48px when `Zen Kaku Gothic New`'s narrower `'0'` glyph replaced `Arial`.
2. Added metric-matched `@font-face` rules (`f12MonoFallbackConsolas` at `size-adjust: 90.91%`, `ascent-override: 110%`, `descent-override: 25.85%` and `f12MonoFallback` at `size-adjust: 83.19%`, `ascent-override: 120.21%`, `descent-override: 28.25%`) directly in `registry/styles/frame12.css`, wired them into `site/app/layout.tsx`, `templates/next-starter/app/layout.tsx`, and `registry/registry.json`, and replaced `ch` width caps with font-swap-invariant `em` units (`34.25em`, `33.25em`, `23.2em`, `15.1em`, `13em`).
3. Result: CLS under `--font-delay-ms=1500` dropped from `0.047–0.334` to **`0.0001–0.0013`** across all 10 routes (recorded in `docs/roadmap/performance-baseline.md`).

## 11. Draft Release Notes: FRAME/12 v0.2.0

**FRAME/12 v0.2.0 grows from a storyboard dashboard kit into a design system for full applications, and every v0.1.0 API stays compatible.**

- **Expressive / Quiet grammar:** `variant="quiet"` on `Panel`, `PanelPair` and `Metric` gives exposure-sheet ledgers that don't consume `C-0n` cut numbers. `<Sheet autoCut>` numbers panels automatically. Non-colour `status` on `Tag`/`Badge`/`Alert`/`Toast` uses glyphs, border styles and screen-reader prefixes. Chart pattern differentiation and `density="compact"` are added.
- **Form kit:** `Field`, `Textarea`, `Checkbox`, `RadioGroup`, `Switch`, `Tabs`.
- **Feedback, loading & navigation kit:** `Alert`/`Notice`, `Toast`, `Skeleton`, `EmptyState`, `Breadcrumb`, `Pagination`.
- **Application blocks:** `developer-console`, `workspace-settings` and `analytics-dashboard` are installable `registry:block` items with deterministic fixtures and loading, empty and error states.
- **Distribution:** 41 registry items (was 22). Shared CSS and hooks come in via `registryDependencies` instead of being copied into every item. Adds `registry:font` and `registry:base` items and `/llms.txt` + `/llms-full.txt`.
- **Quality:** Cross-browser CI in the Playwright image, automated WCAG 2.2 AA checks, forced-colors support, React 18/19 install verification, an AST-based doc-sync checker, and a guardrail fixture suite for the agent skill and static checker.

### Migration guidance

**No migration is required.** No exports, props, CSS classes, tokens or registry item names were removed, and every changed prop type is a widening (§3). Optional adoption steps:

1. **Re-install shared styles once.** Run `npx shadcn add https://frame12.dev/r/frame12-styles.json` (or re-add any component) so `frame12.css` picks up the new Quiet, status and form rules. Individual items now pull it in through `registryDependencies`.
2. **Prefer `<Sheet autoCut>`** over hand-numbered `cut="C-0n"` props. Mixing them logs a development warning, and the checker flags `explicit-cut-in-autocut`.
3. **Use `variant="quiet"`** for subordinate operational groups instead of extra Expressive panels.
4. **Replace raw shadcn primitives** with the new FRAME/12 components. `check-frame12`'s `raw-shadcn-import` rule flags raw `@/components/ui/*` and `@radix-ui/*` imports in application screens.
5. If you use the **starter template**, pull the TF-1 Next.js upgrade before deploying a self-hosted server.
