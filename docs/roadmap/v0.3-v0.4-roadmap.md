# FRAME/12 v0.3 & v0.4 Product & Component Roadmap

- **Status:** Active Post-`v0.2.0` Roadmap
- **Predecessor Audit:** [`docs/roadmap/v0.2-release-readiness.md`](v0.2-release-readiness.md)
- **Design North Star:** Every addition must preserve FRAME/12's Expressive / Quiet design grammar (`Sheet` -> `Scene` -> `Panel`, `C-01..C-0n` narrative cuts vs. `1px` exposure-sheet ledgers, `12fps` on-twos discrete state motion vs. `0ms` continuous input tracking, non-color semantic states, and ADR-001 primitive discipline).

---

## 1. Quick Wins — Promote Patterns Already Proven Inside the `v0.2.0` Blocks (`v0.3.0` Phase 1)

`DeveloperConsole`, `WorkspaceSettings`, and `AnalyticsDashboard` already implement several recurring UI patterns inline. Extracting and formalizing these into first-class, tested registry components immediately raises ergonomics while shrinking block code:

1. **`KeyValueList` / `DescriptionList` (`<dl>` / `<dt>` / `<dd>`):**
   - Formalizes the monospace exposure-sheet metadata grids used across request trace inspectors, endpoint contract cards, and attribution dialogs, with optional one-click copy slots and `density="comfortable" | "compact"`.
2. **`CodeBlock` & `CommandBox`:**
   - Ink-framed code and CLI snippet surface with optional line numbers, line highlights, copy-to-clipboard button with stepped `[+] COPIED` feedback, and multi-tab package-manager switcher (`npm` / `pnpm` / `bun`).
3. **`ActivityFeed` / `EventLogList`:**
   - Formalizes the timestamped, status-badged audit and control-plane event streams from `DeveloperConsole` (`C-05`) and `WorkspaceSettings` into a reusable exposure-sheet log primitive.
4. **`FilterBar` / `Toolbar`:**
   - Standardized Quiet search + `<Select>` filter + `<SegmentedControl>` + active-filter `<Tag>` chip bar with result count and one-click `Reset filters` recovery.

## 2. Composite Devtool & B2B Primitives (`v0.3.0` Phase 2)

To power full-scale developer tools, operational consoles, and B2B SaaS without teams dropping down to unstyled third-party kits:

### High-Impact Interactive Composites
1. **`CommandPalette` (`⌘K`):**
   - Modal exposure-sheet command palette with instant (`0ms`) keyboard filtering, grouped actions, `<Kbd>` shortcut hints, and `C-0n` jump-to-panel navigation.
2. **`Combobox` & `MultiSelect`:**
   - Searchable single- and multi-select with tag pills, async/empty states, and keyboard chip removal—essential for filtering 100+ services, SKUs, or team members.
3. **`FilterBuilder` + `SavedViews`:**
   - Structured `field / operator / value` filter pills (`status IS 5xx`, `latency > 250ms`) with shareable preset views.
4. **`DateRangePicker`:**
   - Preset windows (`24H`, `7D`, `30D`, `90D`, `Custom`) paired with a dual-month ink-grid calendar and explicit timezone indicator (`UTC` / local).
5. **`ResizableSplitPane` & `InspectorDrawer`:**
   - Master-detail split layout and slide-over detail sheet (`Drawer` / `SheetOverlay`) so clicking a table row opens a persistent right-hand trace or record inspector without losing scroll position in the ledger.
6. **`TreeView`:**
   - Keyboard-navigable (`ArrowRight`/`ArrowLeft`/`Home`/`End`) hierarchy for file trees, trace spans, and nested org/permission scopes.
7. **`DataTable` Adapter (`@tanstack/react-table` optional recipe):**
   - Multi-column sorting, sticky header + sticky action column, column visibility menu, bulk row selection action bar, and expandable detail rows while keeping `<Table>` as the zero-dependency primitive.

### Everyday Supporting Primitives
- **`Popover`** (lightweight non-modal anchored surface for inline editors and filter menus)
- **`Drawer` / `SheetOverlay`** (edge-docked slide-over panel using `steps(4, end)` entrance)
- **`Kbd`** (ink-framed keyboard keycap badge, e.g. `⌘` `K`, `T`, `M`, `F8`)
- **`CopyField` / `SecretField`** (masked token display `f12_sim_••••` with reveal toggle and stepped copy confirmation)
- **`Stepper` / `WizardNav`** (multi-step onboarding and deployment progress bar)
- **`UptimeBar` / `ToneHeatmap`** (90-day daily status strips and cohort matrices rendered with SVG screentone densities instead of rainbow gradients)

## 3. Signature Components — Own the "Review, Inspect & Decide" Loop (`v0.3.0` Phase 3)

These components lean directly into FRAME/12's print, proofread, and cel-animation heritage—turning aesthetic identity into functional clarity:

1. **`DiffViewer` & `ChangeReview`:**
   - Unified and split diff viewer for code, JSON configs, and policy changes using `+` / `−` gutter markers, diagonal hatch vs. halftone screentone line highlights (zero reliance on red/green alone), and inline review comment threads.
2. **`LogStream` & `EventViewer`:**
   - High-density monospace log viewer with severity glyph filtering (`[i]`, `[!]`, `[×]`), search highlight, *"Paused — 42 new events"* sticky scroll-lock bar, and `12fps` (`83.33ms`) batch flushing so rapid log bursts step cleanly without layout thrash.
3. **`TraceWaterfall` & `Timeline`:**
   - Exposure-sheet horizontal span waterfall (modeled on animation X-sheets) for distributed traces, CI/CD pipeline stages, and incident timelines, with `83.33ms` frame-budget ruler ticks.
4. **`JsonInspector`:**
   - Collapsible keyboard-navigable payload inspector with path breadcrumbs (`response.body.items[0].id`), byte-size badges, and one-click path/value copy.

## 4. Editorial, Documentation & Print-Heritage Kit (`v0.4.0` Phase 1)

1. **`DocumentAnnotator`:**
   - Editorial reading surface with text-range selection, margin `<Balloon>` callouts, and **edit-resilient anchor resolution** (combining structural block IDs, text quote prefix/suffix context, and character offsets, with an explicit *"Orphaned / Needs Re-anchor"* badge when underlying text changes).
2. **`ApprovalGate` & `PublicationWorkflow`:**
   - Structured review state machine (`Draft` -> `In Review` -> `Changes Requested` -> `Approved` -> `Published`) with required reviewer sign-off checklists and immutable revision stamps.
3. **Editorial Layout Primitives:**
   - **`Prose` / `ArticleLayout` with Margin `Sidenote`s** (numbered footnotes and margin notes aligned to paragraph baselines on desktop, collapsing cleanly inline on mobile)
   - **`Figure`** (ink-framed media container with `C-0n` cut caption, zoom dialog, and aspect-ratio reservation)
   - **`PullQuote`** (`Balloon`-styled editorial callout with speech tail or double-rule border)
   - **`StoryboardGrid`** (multi-cut visual walkthrough for product tours, postmortems, and architecture decision records)
   - **`FocusLines` (Restrained):** Optional SVG radial/linear focus-line backdrop restricted to a single hero or release announcement cut (`max 1 per sheet`, enforced by `check-frame12.mjs`)
   - **`ChangelogTimeline`** & **`DocsShell`** (sidebar tree + main sheet + `"On this page"` scrollspy TOC + `CodeBlock` tabs)

## 5. AI-Native & Agentic Interface Kit (`v0.4.0` Phase 2)

FRAME/12 already leads on **AI-generated UI** (`SKILL.md` + `check-frame12.mjs`). `v0.4.0` pairs that with first-class **UI for operating AI systems**:

1. **`ConversationThread`:**
   - Structured human/agent turn ledger using `<Balloon>` for primary prompts and Quiet exposure-sheet blocks for structured responses, with **token streaming stepped on twos (`12fps` / `83.33ms` buffer flush)** so streaming text reads like deliberate typesetting rather than jittery character reflow.
2. **`AgentRunMonitor`:**
   - Visualizes multi-step agent execution where major plan stages are sequential `C-01..C-0n` cuts and individual tool calls, file reads, and linter checks fold into Quiet collapsible sub-ledgers with elapsed time and token metrics.
3. **`ActionApprovalCard` (Version-Bound Human-in-the-Loop):**
   - High-consequence action gate (deploy, SQL migration, secret rotation, outbound message) that binds the `[Approve & Execute]` button to a specific **proposal hash / revision ID**. If the agent or upstream state mutates the payload while the user is reading, the card invalidates the stale approval and highlights the diff.
4. **`CheckpointBar` & `BranchSelector`:**
   - Snapshot timeline allowing operators to rewind an agent session or workflow to a prior cut, inspect state at that pose, and fork a new run.
5. **`CitationChip` & `EvidenceDrawer`:**
   - Inline numbered source markers (`[1]`, `[S-04]`) that open the exact source excerpt, file line range, or telemetry row alongside the claim.
6. **`SyncStatusBadge`:**
   - Explicit state indicator (`Saved`, `Unsaved changes`, `Syncing…`, `Offline — queued`, `Conflict detected`) with non-color glyphs and conflict resolution dialog trigger.
7. **FRAME/12 MCP Server (`@frame12/mcp`):**
   - Local and remote Model Context Protocol server exposing `list_components`, `get_component_contract`, `get_block_recipe`, and `lint_frame12_code` (wrapping `scripts/check-frame12.mjs`) as live callable tools inside Claude Code, Cursor, Windsurf, and custom agent harnesses.

## 6. Medium-Specific Craft & Platform Capabilities (`v0.4.0` Phase 3)

1. **Bidirectional & Manga Reading Mode (`dir="rtl"` + Vertical Display Option):**
   - Full RTL support for `<Sheet autoCut>` (right-to-left panel reading order verification in `site-verify.mjs`, mirrored diagonal `<PanelPair>` slants, and optional `writing-mode: vertical-rl` display eyebrows for authentic manga/Japanese editorial layouts).
2. **View Transitions on Twos:**
   - Optional integration with the browser View Transitions API (`document.startViewTransition`) stepped at `steps(3, end)` / `steps(4, end)` (`--f-step-3`, `--f-step-4`) and automatically disabled under `prefers-reduced-motion: reduce`.
3. **Print & PDF Storyboard Stylesheet (`@media print`):**
   - Dedicated print rules in `registry/styles/frame12.css` so any `<Sheet>` exports to crisp, high-contrast black-and-white A4 / Letter pages with intact SVG panel borders, visible `C-0n` cut badges, expanded `<Table>` ledgers, and zero clipped scroll containers.
4. **W3C Design Tokens (`tokens.dtcg.json`) & Figma Variables Export:**
   - Automated build script emitting W3C Design Tokens Community Group (`$value`, `$type`) JSON from `registry/styles/frame12.css` for one-click import into Figma Variables and Style Dictionary pipelines.

## 7. Two New Flagship Application Blocks (`v0.4.0`)

1. **`agent-review-console` (`registry:block`):**
   - Combines `AgentRunMonitor`, `ConversationThread`, `DiffViewer`, `ActionApprovalCard`, and `CitationChip` into a complete human-in-the-loop engineering review workbench.
2. **`editorial-review-desk` (`registry:block`):**

## 8. Engineering Quality Gates Beyond Component Count

1. **Automated Visual Regression Snapshots:** Per-component, per-state pixel/geometry snapshot assertions across Chromium, Firefox, and WebKit in CI.
2. **Recorded Human Screen-Reader Verification:** Completed VoiceOver (macOS) and NVDA (Windows) sign-off logs in [`docs/ACCESSIBILITY.md`](../ACCESSIBILITY.md) for `Dialog`, `Tabs`, `Select`, `DropdownMenu`, `Toast`, `ToneAreaChart`, and the new composite widgets.
3. **Live Multi-Run LLM Benchmark Suite (`eval/agent-eval/`):** Complement the deterministic guardrail fixture suite with recorded, multi-run live model evaluations (pinned model IDs, prompts, raw transcripts, and pass@k metrics across C1–C4).
4. **Versioned Registry Endpoints:** Publish immutable `/r/v0.2/<name>.json` and `/r/v0.3/<name>.json` paths alongside `/r/<name>.json` so production consumers can pin major/minor registry versions.
5. **Strict Bundle Isolation for Heavy Adapters:** Keep the core 31+ primitives zero-dependency (plus Radix `Select`/`DropdownMenu` per ADR-001), shipping heavy integrations (`@tanstack/react-table`, syntax highlighting) as opt-in adapter items.
