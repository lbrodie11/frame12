# FRAME/12 Launch Clips & Social Assets (`launch/clips/`)

This directory holds the recorded comparison video and high-DPI static hero card generated by `launch/scripts/record-clip.mjs`.

## Generated Assets

| File | Dimensions / Spec | Description |
| --- | --- | --- |
| `motion-on-twos.webm` | `1280×720` (VP8/VP9 WebM, ~19s) | Three-part live capture of `/motion`: **Phase A** (`Smooth · 60fps` continuous easing across `7 → 90 → 30 days`), **Phase B** (`Stepped · 12fps` on twos with `83.33ms` exposure-sheet poses, `mix-blend-mode: difference` marker inversion, stepped screentone wipe, and 2-frame SVG burst), and **Phase C** (synchronized side-by-side replay in Light paper and Dark flashback themes). |
| `social-hero.png` | `1200×630` (`2400×1260` @ 2x DPI) | Static Open Graph / social hero card showing the FRAME/12 registration-pegged sheet, `C-01` 45° screentone area chart with speech-balloon peak annotation, `C-02`/`C-03` diagonal `PanelPair` across a `12px` pair gutter, and `C-04` exposure-sheet film strip. |

## Regenerating the Clips

Build `@frame12/site` once, then run the Playwright recording script from the repository root:

```bash
npm --workspace site run build
node launch/scripts/record-clip.mjs
```

## Converting `motion-on-twos.webm` to a Palette-Optimized GIF (`ffmpeg`)

When `ffmpeg` is installed on your machine, `node launch/scripts/record-clip.mjs` automatically generates `launch/clips/motion-on-twos.gif`.

If `ffmpeg` is not installed locally (installable on macOS via `brew install ffmpeg`), run the following command to produce a high-clarity, palette-optimized GIF at **24fps** (an exact `2×` multiple of `12fps`, ensuring every `83.33ms` held pose stays locked on two frames without frame-rate jitter):

```bash
ffmpeg -y -i launch/clips/motion-on-twos.webm \
  -vf "fps=24,scale=960:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=128:stats_mode=diff[p];[s1][p]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle" \
  -loop 0 \
  launch/clips/motion-on-twos.gif
```

For an explicit two-pass workflow (`palette.png` → `motion-on-twos.gif`):

```bash
# Pass 1: Generate an ink/paper/marker-accurate 128-color palette
ffmpeg -y -i launch/clips/motion-on-twos.webm \
  -vf "fps=24,scale=960:-1:flags=lanczos,palettegen=max_colors=128:stats_mode=diff" \
  launch/clips/palette.png

# Pass 2: Render the GIF at 24fps (2 frames per 83.33ms pose)
ffmpeg -y -i launch/clips/motion-on-twos.webm -i launch/clips/palette.png \
  -lavfi "fps=24,scale=960:-1:flags=lanczos[x];[x][1:v]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle" \
  -loop 0 \
  launch/clips/motion-on-twos.gif

rm -f launch/clips/palette.png
```
