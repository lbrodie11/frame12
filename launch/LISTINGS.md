## 1. Official `shadcn/ui` Registry Directory

- **Documentation & Directory URL:** `https://ui.shadcn.com/docs/directory`
- **Submission Target (GitHub PR):** `https://github.com/shadcn-ui/ui` → `apps/v4/registry/directory.json`

### Verified Technical Requirements
1. **Public & Open Source:** The repository and hosted endpoints (`https://frame12.dev/r/*.json`) must be publicly accessible over HTTPS with CORS enabled.
2. **Valid `registry.json` Schema:** Must conform to `https://ui.shadcn.com/schema/registry.json` (`site/public/r/registry.json` generated by `npx shadcn build`).
3. **Flat Endpoint Structure:** Individual registry items must resolve at flat URLs (`https://frame12.dev/r/{name}.json`) without nested path segments.
4. **Source `registry.json` Format:** In `registry/registry.json`, item `files` entries must list `path` and `type` (without inline `content` in the index file; `shadcn build` compiles the payload into `site/public/r/*.json`).
5. **Local Validation Command (inside `shadcn-ui/ui` fork):**
   ```bash
   pnpm validate:registries
   ```

### Pre-Filled `apps/v4/registry/directory.json` Entry
